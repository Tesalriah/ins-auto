# 🚀 인스타그램 댓글 & DM 자동화 가이드 (User Manual)

본 도구는 인스타그램 게시물의 댓글을 감지하여 자동으로 답글을 달고 DM을 전송하는 지능형 자동화 시스템입니다.

---

## 📋 1. 사전 준비 사항

1.  **Node.js 설치**: 최신 LTS 버전을 권장합니다.
2.  **Google Chrome**: 맥(macOS)의 `/Applications` 폴더에 정식 버전이 설치되어 있어야 합니다.
3.  **Supabase 계정**: 데이터 저장을 위한 프로젝트가 필요합니다.
    - `tasks` 테이블과 `comments_history` 테이블이 생성되어 있어야 합니다. (기획안 `PROJECT_SPEC.md` 참조)

---

## ⚙️ 2. 설치 및 설정

### 1) 프로젝트 내려받기 및 의존성 설치
```bash
# 백엔드 폴더로 이동
cd backend

# 필요한 라이브러리 설치
npm install
```

### 2) 환경 변수 설정
`backend/.env.example` 파일을 복사하여 `.env` 파일을 생성합니다.
```bash
cp .env.example .env
```
생성된 `.env` 파일에 본인의 Supabase 정보를 입력합니다.
- `SUPABASE_URL`: 본인의 프로젝트 URL
- `SUPABASE_KEY`: 본인의 anon public key

---

## 🚀 3. 사용 방법

### 1) 엔진 실행
```bash
# backend 폴더에서 실행
npm start
```

### 2) 로그인 단계 (최초 1회 또는 세션 만료 시)
- 브라우저가 자동으로 열리고 인스타그램 로그인 페이지가 나타납니다.
- **직접 아이디와 비밀번호를 입력하여 로그인을 완료**하세요.
- 로그인이 완료되어 '홈 피드'가 보이면, 엔진이 이를 감지하고 자동으로 작업을 시작합니다.
- 로그인 성공 시 `session.json` 파일이 생성되어 이후 실행부터는 로그인이 생략됩니다.

### 3) 작업 진행 상황 확인
- 터미널(콘솔)을 통해 현재 어떤 게시물을 탐색 중인지, 누구에게 답글과 DM을 보냈는지 실시간 로그를 확인할 수 있습니다.
- 모든 작업이 완료되면 브라우저가 자동으로 닫힙니다.

---

## 🔄 4. 계정 전환 방법

다른 인스타그램 계정을 사용하고 싶을 때는 간단합니다.
1.  `backend/session.json` 파일을 삭제합니다.
2.  `npm start`를 다시 실행합니다.
3.  새로운 브라우저 창에서 원하는 계정으로 로그인합니다.

---

## ⚠️ 5. 주의 사항 및 보안

-   **보안**: `session.json` 및 `.env` 파일은 절대 외부에 공유하거나 Git에 올리지 마세요. (이미 `.gitignore`로 보호되고 있습니다.)
-   **차단 방지**: 너무 짧은 시간 안에 너무 많은 댓글에 작업을 수행하면 인스타그램으로부터 계정이 일시 제한될 수 있습니다. (엔진에 랜덤 지연 시간이 포함되어 있으나 주의가 필요합니다.)
-   **정식 크롬 사용**: 본 엔진은 안정성을 위해 설치된 Google Chrome을 직접 제어합니다. 실행 중에는 크롬 창을 임의로 닫지 마세요.

---

## 🛠 6. 문제 해결 (Troubleshooting)

-   **게시물을 찾지 못함**: 게시물이 삭제되었거나 본인 프로필에서 보이지 않는 상태인지 확인하세요.
-   **DM 발송 실패**: 상대방이 DM 수신을 차단했거나, 내가 팔로우하지 않은 사람에게 DM을 보낼 수 없는 계정 상태일 수 있습니다.
-   **로그인 무한 대기**: 인터넷 연결을 확인하고, 브라우저에서 로그인을 완전히 마쳤는지 확인하세요.
