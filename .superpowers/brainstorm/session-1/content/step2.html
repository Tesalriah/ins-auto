방식 선택 완료: 직접 자동화 (Option C)

계정 정지 위험이 있으므로 주의가 필요하며, 기술적으로 가장 도전적인 방식입니다.

현재 결정 사항

  • 도구: Puppeteer 또는 Playwright (브라우저 제어)
  • 핵심 기능: 댓글 감지 -> DM 발송 -> 답글 작성

질문 2: 구동 환경

브라우저를 직접 제어하는 스크립트는 일반적인 서버리스 환경(Supabase Edge Functions 등)에서 실행하기 어렵습니다. 어디서 구동하기를 원하시나요?

A

로컬 컴퓨터

개발 중인 본인의 PC에서 필요할 때마다 실행

B

개별 클라우드 서버 (VPS)

AWS, GCP 등의 서버에서 24시간 자동 구동

C

일단 로컬에서 개발 후 고민

기능 구현을 먼저 완료한 뒤 배포 환경 결정
