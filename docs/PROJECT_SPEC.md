# 인스타그램 댓글 및 DM 자동화 시스템 (Instagram Automation Tool) 기획 및 명세서

## 1. 프로젝트 개요
본 프로젝트는 인스타그램 게시물의 댓글을 실시간으로 감지하여, 작성자에게 자동으로 답글을 달고 개인 메시지(DM)를 발송하는 자동화 솔루션입니다. 사용자의 계정 보안을 최우선으로 고려하여 수동 로그인 방식을 채택하였으며, 실제 사람의 행동을 모방(Human-Simulation)하여 차단 위험을 최소화합니다.

## 2. 주요 기능 (Core Features)

### 2.1 보안 중심의 인증 (Manual Authentication)
- **수동 로그인:** 자동 쿠키 저장 방식 대신 매 실행 시마다 사용자가 직접 브라우저에서 로그인하도록 설계하여 계정 보안을 강화했습니다.
- **실시간 대기:** 로그인 페이지 접속 후 사용자가 홈 피드에 도달할 때까지 엔진이 지능적으로 대기합니다.

### 2.2 지능형 댓글 탐색 및 답글 (Smart Reply)
- **프로필 기반 진입:** 직접 URL 접속 대신 본인 프로필 피드를 통해 게시물에 접근하여 인스타그램의 봇 탐지 알고리즘을 회피합니다.
- **범용적 요소 탐색:** 인스타그램의 복잡한 HTML 구조를 분석하여 '답글 달기' 버튼과 유저네임을 정확하게 식별합니다.
- **시간 정보 필터링:** 작성자 이름 대신 시간 정보(예: 10분, 1시간)를 가져오지 않도록 정교한 텍스트 필터링을 적용했습니다.
- **중복 방지:** Supabase DB와 연동하여 이미 처리된 댓글은 자동으로 건너뜁니다.

### 2.3 안정적인 DM 발송 (Reliable DM)
- **새 탭 방식:** 게시물 페이지의 상태를 유지하기 위해 DM 발송 시에만 별도의 탭을 열어 작업을 수행합니다.
- **다중 선택자 대응:** 인스타그램의 다양한 DM 입력창(div textbox, textarea 등)을 모두 지원합니다.
- **전송 이중 확인:** Enter 키 입력과 전송 버튼 클릭을 병행하여 메시지 발송의 성공률을 극대화했습니다.

## 3. 기술 스택 (Tech Stack)
- **언어:** TypeScript
- **런타임:** Node.js
- **자동화 도구:** Puppeteer (정식 Google Chrome 연동)
- **데이터베이스:** Supabase (PostgreSQL)
- **환경 관리:** dotenv (환경 변수 관리)

## 4. 데이터 모델 (Data Model)

### `tasks` (자동화 작업 설정)
- `post_url`: 대상 게시물 주소
- `dm_content`: 발송할 DM 내용
- `reply_content`: 작성할 답글 내용
- `is_active`: 작업 활성화 상태

### `comments_history` (처리 이력)
- `task_id`: 연결된 작업 ID
- `instagram_comment_id`: 고유 댓글 식별자 (유저네임 + 메시지 일부)
- `username`: 댓글 작성자 아이디
- `processed_at`: 처리 완료 시각

## 5. 아키텍처 및 워크플로우 (Workflow)
1. **엔진 기동:** 정식 Google Chrome 브라우저 실행.
2. **로그인 대기:** 사용자가 직접 로그인 완료할 때까지 대기.
3. **프로필 이동:** 본인 프로필 페이지 진입 및 대상 게시물 탐색.
4. **댓글 분석:** 새 댓글 대상 수집 및 DB 대조.
5. **답글 게시:** 게시물 내부에서 답글 작성 및 전송.
6. **DM 발송:** 새 탭을 열어 유저 프로필 방문 후 DM 발송.
7. **이력 저장:** 처리 완료된 댓글 정보를 DB에 기록.

## 6. 보안 및 안정성 조치
- **정식 크롬 사용:** Puppeteer 기본 브라우저 대신 시스템 크롬을 사용하여 기능 제한 및 봇 탐지 확률을 낮췄습니다.
- **랜덤 지연:** 작업 단계별로 랜덤한 대기 시간(Random Delay)을 추가하여 기계적인 패턴을 제거했습니다.
- **수동 로그인 유지:** 세션 정보를 파일로 저장하지 않아 개인정보 유출 위험을 방지했습니다.
